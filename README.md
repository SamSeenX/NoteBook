# Notes PWA

A fast, minimalist, offline-first notes application built with pure Vanilla JavaScript, modern CSS, and Vite.

## Features
- **Sidebar Organization**: Manage multiple notes with titles and optional descriptions.
- **Search & Sort**: Real-time fuzzy query filtering with sorting by modified date, created date, or title.
- **Pinning**: Keep critical notes pinned to the top of the sidebar.
- **Markdown & Simple Notes**: Toggle between plain text and markdown formats with live preview.
- **WYSIWYG Formatting Toolbar**: Quick actions for headers, bold, italics, quotes, lists, and code blocks.
- **Multipage PDF Export**: Clean, zero-bloat PDF printing engine with native page breaks.
- **Offline First**: IndexedDB document persistence and localStorage UI state with JSON backup/restore.

## Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
