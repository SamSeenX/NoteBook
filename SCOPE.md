# SCOPE.md - Project Boundaries & Features

## In Scope
- Offline-first Progressive Web App with standalone display
- Collapsible sidebar with list of notes
- Note metadata: Title, optional description, created date, modified date
- Inline `#tags` filtering and dynamic tag cloud
- Trash recovery and soft-delete system
- Zen / Focus writing mode
- Drag-and-drop file import (.md, .txt)
- Search query filtering across titles, descriptions, and content
- Sorting options: Modified date (newest/oldest), Created date, Title (A-Z, Z-A)
- Pinning notes to top of sidebar
- Plain text & Markdown editing with syntax formatting toolbar
- View toggles: Editor only, Preview only, Split view
- Typography toggle: Sans-serif vs Monospace
- Native multipage PDF export via print stylesheet
- 1-click JSON backup export and file restore
- Word count, character count, estimated reading time, and live auto-save status indicator
- Accessible custom modals and toast notifications

## Out of Scope
- Backend cloud databases and authentication servers
- Third party heavyweight rich text editors
- Synchronous cloud syncing accounts (keeps app zero-cost, local-first, privacy-focused)
